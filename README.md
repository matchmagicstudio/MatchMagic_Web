# MatchMagic Website

Public landing website for [MatchMagic](https://matchmagic.app) — an educational matching game for children ages 2–6.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Go to [vercel.com](https://vercel.com) and sign in.
3. Click **Add New… → Project** and import the repository.
4. Vercel auto-detects Next.js — keep the default settings.
5. Click **Deploy**.

Alternatively, from the project directory:

```bash
npx vercel
```

Follow the prompts to link and deploy.
